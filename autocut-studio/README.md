# Autocut Studio

浏览器端自动剪辑网站 MVP，支持上传视频、智能镜头分析、2K/4K 输出、自动转场、特效预设和手动精修。

## 启动

```bash
pnpm install
pnpm build
pnpm start
```

打开 `http://127.0.0.1:8787`。

## 当前能力

- 浏览器本地读取视频元数据并抽样分析镜头、运动、曝光和色彩变化
- 根据剪辑风格自动规划转场和特效
- 支持 2K、4K，以及 16:9、9:16、1:1 输出
- 支持裁剪入点、出点、分割、复制、删除、隐藏和镜头排序
- 支持 0.5x 至 2x 变速、音量调节、静音，以及画面铺满或适配
- 支持撤销和重做编辑操作
- 后端使用 FFmpeg 渲染镜头、转场和特效并封装成 MP4
- 支持方案 JSON 导出、任务进度和成片下载

## 接入真实 AI 服务

当前镜头分析位于 `src/lib/analyzer.ts`。接入 ASR、视频理解模型或 LLM 时，保留前端返回的场景时间线结构即可，渲染服务不需要重写。

建议的分析顺序：

1. ASR/字幕生成，获得语义段落和关键词。
2. 镜头边界检测，获得硬切和场景转换位置。
3. 视频理解模型判断情绪、景别、动作和内容重点。
4. 音乐节拍和音频能量检测。
5. LLM 输出标准剪辑决策列表，交给 FFmpeg 渲染。

生成式转场需要单独的视频生成模型，不属于当前 MVP 的渲染路径。

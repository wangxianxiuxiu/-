# 拾帧 · 个人视频库

移动端优先的个人视频标签与收藏界面，底部使用参考图风格的悬浮胶囊 Dock。

默认搜索方案使用 [TikHub API](https://tikhub.io/)，支持抖音、快手、哔哩哔哩和 TikTok 关键词搜索。新账号约提供 50 次免费请求，实际额度和价格以 TikHub 控制台为准。项目仅供个人学习与研究使用。

## 功能

- 视频标签分为服装穿搭、舞蹈和生活方式。
- 标签可搜索，点击后进入筛选后的视频流。
- 视频页提供搜索优先界面，可搜索抖音、快手、哔哩哔哩和 TikTok 视频。
- 支持粘贴抖音、快手、哔哩哔哩或 TikTok 分享链接/分享文本直接识别视频。
- 无 API Key 时可使用公开 Demo 模式预览固定抖音缓存。
- 在 TikHub 模式下未填写 Key 时，搜索会自动回退到 Demo，不再返回空白页。
- 搜索结果会根据平台响应统一为标题、作者、封面、视频地址、时长和标签。
- 哔哩哔哩播放地址在打开单条视频时按需解析，避免搜索阶段产生大量额外请求。
- 搜索结果会追加到本地视频库。
- 底部新增“已获取”入口，可查看和筛选所有历史获取过的视频。
- 已获取视频支持按平台、标题、作者、标签搜索，并支持最近或热度排序。
- 视频列表只负责浏览，不显示保存操作。
- 单条视频页面显示上一个、保存视频和下一个。
- 保存记录、设置和采集结果存储在浏览器本地。
- 底部 Dock 适配手机、平板和桌面。

## 启动

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

打开 `http://127.0.0.1:4173`。

## 使用

1. 在设置中选择 `TikHub API` 并填写 API Key。
2. 也可以先选择 `公开 Demo` 查看无 Key 预览。
3. 点击“测试连接”，确认 API Key 有效。
4. 回到视频页，选择抖音、快手、哔哩哔哩或 TikTok 并输入关键词。
5. 搜索结果会直接追加到视频流并支持标签筛选。
6. 在设置中填写“自动采集关键词”，开启后会在网页保持打开时轮换搜索。

## 本地备用方案

`collector/MediaCrawler` 仍然保留，但默认不再使用。需要时可以：

```powershell
powershell -ExecutionPolicy Bypass -File .\collector\setup.ps1
powershell -ExecutionPolicy Bypass -File .\collector\start.ps1
```

然后在设置页将 API 模式切换为“本地 MediaCrawler”。
